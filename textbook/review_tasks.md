Блок 1. Азбука (Задачи 1–10)

Цель: Синтаксис, типы данных, ветвления, циклы, простые функции.

    Калькулятор деления. Напишите программу, которая принимает два числа и выводит частное. Обработайте деление на ноль через if.

    Таблица умножения. Выведите в консоль таблицу Пифагора (10x10) с помощью вложенных циклов, форматируя вывод в столбцы.

    Число Фибоначчи. Реализуйте итеративную функцию, возвращающую N-е число Фибоначчи. Затем реализуйте рекурсивную версию и сравните скорость для N=40.

    Реверс строки. Напишите функцию, которая переворачивает переданную C-строку (массив char) на месте, без использования std::reverse.

    Игра "Угадай число". Генерация случайного числа, цикл do-while, подсказки "больше/меньше". Подсчет попыток.

    Структура Student. Создайте структуру с полями (имя, возраст, 3 оценки). Напишите функцию вычисления среднего балла и вывода лучшего студента из массива.

    Динамический массив. Выделите память под массив интов через new, заполните его, отсортируйте пузырьком и очистите через delete[].

    Работа с файлами. Запишите в текстовый файл 100 случайных чисел, затем прочитайте их, найдите максимум и минимум.

    Перегрузка функций. Напишите три функции с именем square: для int, double и int* (возвращает квадрат значения по указателю).

    Шифр Цезаря. Напишите функцию, сдвигающую буквы в строке на K позиций. Работа только с латиницей (учтите переход z -> a).

Блок 2. Знакомство с ООП и STL (Задачи 11–20)

Цель: Классы, наследование, векторы, строки, алгоритмы.

    Класс Vector2D. Реализуйте класс с полями x, y, конструкторами, перегрузкой операторов +, -, * (скаляр), и методом length().

    Счетчик объектов. Добавьте в класс Vector2D статическую переменную, считающую количество созданных объектов. Выведите ее при завершении программы.

    Наследование. Класс Animal (виртуальный метод speak()) и производные Dog, Cat. Положите их в вектор указателей и вызовите speak полиморфно.

    Умный указатель. Перепишите задачу 13, используя std::unique_ptr вместо сырых указателей.

    Поиск в векторе. Заполните std::vector<int> 1000 случайных чисел. Используйте std::find и std::sort из <algorithm>. Замерьте время.

    Контейнер std::map. Создайте частотный словарь: подсчитайте количество вхождений каждого слова в тексте (используйте std::stringstream для разбивки).

    Итераторы. Напишите шаблонную функцию printContainer, которая принимает любые итераторы (begin/end) и выводит элементы через запятую.

    Класс String (свой). Создайте класс-обертку над char*. Реализуйте конструктор копирования, оператор присваивания и деструктор (Правило Трех).

    Исключения. Добавьте в класс String метод at(index), который выбрасывает std::out_of_range, если индекс вне границ. Перехватите исключение в main.

    Лямбда-функции. Отсортируйте вектор студентов по убыванию среднего балла, используя std::sort и лямбду.

Блок 3. Шаблоны, STL сложные части и move-семантика (Задачи 21–30)

Цель: Методологии современного C++ (C++11/14/17).

    Шаблонный стек. Реализуйте стек на массиве фиксированного размера как шаблонный класс. Добавьте метод emplace (конструирование на месте).

    SFINAE. Напишите шаблон, который проверяет, есть ли у типа метод foo(). Выведите разное сообщение в static_assert.

    Move-конструктор. Добавьте в класс String из задачи 18 перемещающий конструктор и перемещающий оператор присваивания (Правило Пяти). Докажите, что он вызывается.

    Приоритетная очередь задач. Используйте std::priority_queue с компаратором для выполнения задач с наивысшим приоритетом.

    Пул потоков (основа). Создайте класс ThreadPool с фиксированным числом потоков. Поставьте в очередь 10 задач (лямбд) и выполните их с помощью std::async или std::thread + условных переменных.

    std::variant и std::visit. Создайте тип "Данные", который может быть int, double или std::string. Напишите функцию, выводящую значение без if-else (используйте std::visit + лямбду-оверлоад).

    Фабрика с CRTP. Реализуйте базовый шаблонный класс Singleton<T>, где каждый наследник получает единственный экземпляр через CRTP (Curiously Recurring Template Pattern).

    Аллокаторы. Напишите свой простой линейный аллокатор (выделяет память большим блоком и раздает кусками) и подключите его к std::vector<int>.

    Парсер аргументов. Напишите класс, который парсит аргументы командной строки (--input file.txt --verbose). Используйте std::unordered_map.

    Асинхронный таймер. Используйте std::future и std::async, чтобы запустить функцию, которая выполняется 5 секунд. Установите тайм-аут ожидания в 2 секунды (используйте wait_for).

Блок 4. Системное программирование и память (Задачи 31–40)

Цель: Работа с ОС, памятью, производительностью, низкоуровневое IO.

    Memory Mapped File. Отобразите файл в память (через mmap в Linux или CreateFileMapping в Windows) и подсчитайте в нем количество байт 'A' без чтения в пользовательский буфер.

    Параллельное вычисление суммы. Разбейте большой вектор на чанки, запустите std::thread для каждого чанка, сложите результаты через std::atomic<int>.

    SpinLock. Реализуйте простой мьютекс на основе атомарного флага (std::atomic_flag) с busy-wait. Сравните время работы с std::mutex в 10 потоках.

    Сигналы (POSIX). Напишите обработчик для SIGINT (Ctrl+C), который корректно завершает программу, сохраняя промежуточные данные в файл.

    Самодельный shared_ptr. Реализуйте упрощенный аналог с контрольным блоком счетчика ссылок. Без слабых ссылок, только базовый механизм.

    Прокси-сервер (однопоточный). Напишите программу, которая слушает локальный порт, принимает подключение, читает запрос и перенаправляет его на внешний сайт (через socket), возвращая ответ клиенту.

    Работа с /proc (Linux). Напишите утилиту, которая читает /proc/self/status и /proc/self/maps, чтобы вывести текущее потребление памяти (VmRSS) и список загруженных библиотек.

    Буферизированный ввод. Реализуйте свой класс FastScanner, который читает из файла огромными блоками (8192 байт) и парсит оттуда числа быстрее, чем std::ifstream >> int.

    Перехват системных вызовов (LD_PRELOAD). Напишите разделяемую библиотеку (.so), которая переопределяет malloc и free, логируя каждый вызов в консоль. Подгрузите ее к любой программе.

    Двойной буфер (Double Buffer). Реализуйте потокобезопасный обмен данными между продюсером и консьюмером через два буфера с атомарным переключением указателя (без локов на чтение).

Блок 5. Сложный системный низкоуровень, сети и хакинг (Задачи 41–50)

Цель: Вопросы с собеседований в Yandex/Google/системные команды. Знание ABI, уязвимостей, нестандартных приемов.

    (Собеседование: ABI) Инъекция кода в чужой процесс. Напишите программу под Linux, которая приаттачивается к запущенному процессу по PID с помощью ptrace, внедряет в его память код (машинные инструкции), который просто увеличивает счетчик, и запускает этот код удаленно.
    Проверяет: знание ptrace, waitpid, машинных кодов, защиты памяти (mprotect).

    (Собеседование: Производительность) Cache-Friendly MatMul. Напишите умножение матриц (1024x1024) тремя способами: наивный i,j,k; с перестановкой циклов i,k,j; и с использованием блоков (блочная память). Замерьте разницу в 50 раз. Объясните промахи кэша L1/L2.
    Проверяет: понимание архитектуры CPU, кэшей, prefetching.

    (Собеседование: Сети) SYN-флуд (сырые сокеты). Создайте "сырой" сокет (SOCK_RAW) и сформируйте вручную Ethernet/IP/TCP заголовки (без библиотек). Отправьте 10 SYN-пакетов на открытый порт сервера с поддельным IP-адресом (spoofing).
    Проверяет: знание стека TCP/IP, struct sockaddr_ll, checksum calculation.

    (Собеседование: Undefined Behavior) Type Punning и Strict Aliasing. Напишите функцию, которая интерпретирует биты float как int32_t двумя способами: через reinterpret_cast (UB) и через memcpy (стандартный). Покажите, как компилятор с оптимизацией -O2 переставляет операции в первом случае, ломая логику.
    Проверяет: знание стандарта, оптимизаций компилятора, ассемблера (-S).

    (Собеседование: Хакинг памяти) Heap Overflow exploitation (учебный). Напишите две структуры в куче подряд. Переполните буфер в первой структуре так, чтобы затереть виртуальную таблицу (vptr) второй структуры и перенаправить вызов виртуальной функции на ваш "подставной" объект (на основе примера из книги "Hacking: The Art of Exploitation").
    Проверяет: понимание размещения объектов в памяти, vtable, защиты ASLR (отключите её для эксперимента).

    (Собеседование: Lock-free) Ring Buffer (MPSC). Реализуйте однопоточный продюсер и многопоточный консьюмер (или наоборот) без мьютексов, используя только std::atomic и последовательности (memory_order_release/acquire) для кольцевого буфера фиксированного размера.
    Проверяет: знание модели памяти C++, акира-конструкции, ABA problem.

    (Собеседование: Компиляторы) Рефлексия в compile-time. Напишите макрос или шаблон, который по имени структуры генерирует JSON-сериализатор без использования RTTI, используя макросы для описания полей (например, REFLECT(MyStruct, (field1)(field2))). Реализуйте итерацию по полям в constexpr функциях.
    Проверяет: макросы X-Macro, if constexpr, работа с tuple и boost::fusion (или самописный вариант).

    (Собеседование: Асинхронность) Event Loop с epoll. Напишите высокопроизводительный эхо-сервер на epoll (edge-triggered) с неблокирующими сокетами. Он должен принимать 10000 подключений и отражать данные обратно, используя один поток. Добавьте таймеры (timeout) для отключения неактивных клиентов.
    Проверяет: системные вызовы epoll_ctl, EPOLLET, fcntl(O_NONBLOCK), обработка EAGAIN.

    (Собеседование: Шифрование и маскировка) Обфускация строк. Реализуйте механизм, при котором строковые литералы (пароли, ключи API) не хранятся в секции .rodata бинарника в открытом виде, а дешифруются на лету при первом использовании (XOR с случайным ключом, генерируемым в compile-time с помощью constexpr).
    Проверяет: constexpr функции, работа с массивами символов, понимание компоновки ELF.

    (Собеседование: Архитектура ОС) Загрузчик исполняемых файлов. Напишите программу, которая открывает на диске другой .elf (Linux) или .exe (PE) файл, анализирует его заголовки (секции/сегменты), выделяет в текущем процессе память в нужных местах (с использованием mmap), релокирует динамические ссылки (обработка .rela.plt), и передает управление на точку входа, загружая таким образом бинарник без execve().
    Это задача уровня "системный программист ядра ОС". Проверяет: знание форматов исполняемых файлов, виртуальной памяти, ELF-хедера, перемещений.
